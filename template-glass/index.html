Keyboard
Standalone ND-500, running NDIX. Boots straight off the root disc - no kernel to choose. The root disc is either the server's own NDIX image (downloaded at power-on, like the ND-100's demo SMD pack) or one tagged ND-500 / NDIX root in the local disk library.
Root disc
NDIX writes to its root disc as it runs. The disc is loaded into memory for the session and nothing is written back to the server or the library, so leave this on; untick it only to run the disc read-only.
